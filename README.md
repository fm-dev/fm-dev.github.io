# Muhammad Fajri Afriyansyah

A static portfolio for GitHub Pages. Open `index.html` in a browser or use a local static server. No dependency installation or build step is required.

- `index.html`: profile, four employment records, projects, education, skills, and contact details.
- `css/portfolio.css`: layout and responsive styles.
- `tokens.css` and `base.css`: design tokens and base styles for the Hallmark Studio theme.
- `js/portfolio.js`: mobile navigation. Content and project details remain accessible without JavaScript.

Employment details were supplied by the profile owner from LinkedIn on 3 November 2026. Academic contributions include links to official PCR sources. Fonts are loaded from Google Fonts with local fallback fonts.

Original template files are retained but are not loaded by the main page. Local verification results and screenshots are stored in `.hallmark/`, which is excluded from Git tracking.
